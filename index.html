Atlas Content Pipeline

一键将知识库笔记转换为结构化网站文章 — 自动解析、分类、验证，生成符合 Astro 前端 Schema 的文章文件。

GitHub 仓库 快速开始

核心功能

从知识库导出到结构化文章的完整 ETL 管道

智能解析

自动从 GetNote Markdown 导出中提取独立笔记条目，解析标题、标签、创建时间。

  • 正则表达式精确匹配
  • 支持批量笔记解析
  • 保留原始元数据

P0 内容筛选

基于关键词权重的智能评分，自动识别 HSK 1-3、日常用语等启动内容。

  • 24+ 正面关键词
  • 6+ 负面关键词过滤
  • 可按 ID 或排名选择

LLM 推理

调用 Claude API 自动生成分类、HSK 级别、标签、摘要和优先级。

  • 支持 3 种 Provider 模式
  • JSON Schema 严格校验
  • 自动重试机制

本地规则引擎

无需 API Key 的启发式模式，本地规则推断完整的 frontmatter 元数据。

  • 零外部依赖
  • 分类/意图/受众推断
  • 标签自动生成

结构化输出

按分类目录组织文章，包含完整 YAML frontmatter 和 manifest 索引。

  • 分类目录 + Markdown 文件
  • Manifest JSON 索引
  • 跳过列表报告

容错设计

单条笔记失败不影响整体运行，完整错误日志和跳过报告。

  • 失败自动重试
  • 详细错误报告
  • skipped.json 追踪

Provider 模式

三种推理引擎，灵活适配不同场景

anthropic-api

直接调用 Anthropic Messages API。适合有 API Key，需要高质量 LLM 推理的场景。

需要 ANTHROPIC_API_KEY

claude-cli

本地 Claude CLI 封装。适合已安装 Claude CLI 的开发者。

需要安装 claude CLI

heuristic (推荐入门)

本地规则引擎，无需任何 API Key。适合验证管道流程和零成本运行。

零依赖，免费

快速开始

Python 3.9+，零外部 Python 依赖

# Dry-run：解析 + 选择候选（不写入文件） python3 scripts/getnote_frontmatter_pipeline.py --dry-run --limit 30 # Heuristic 模式：30 条试点运行（无需 API Key） python3 scripts/getnote_frontmatter_pipeline.py \ --provider heuristic --limit 30 --selection p0-seed # LLM 模式：Claude 推理 frontmatter python3 scripts/getnote_frontmatter_pipeline.py \ --provider anthropic-api --limit 30 --selection p0-seed \ --model claude-sonnet-4-0
